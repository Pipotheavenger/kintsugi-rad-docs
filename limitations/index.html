    Missing data and metrics¶

    • Data: metadata CSVs, audio buckets and logmel_energies.npy are private (GCS/W&B); no checkpoints or teacher scores (score_targets_csv) are included.
    • Preprocessing: VAD and resampling are upstream and not in the repo; only the VAD parameters remain (kirad/constants.py:21).
    • Outcomes: only PHQ-9 and GAD-7 are wired in configs; a binary real task (exact2, cutoff 0) exists in kirad/constants.py but no config uses it (candidate for SCID).
    • Metrics: no calibration, no per-country / per-language breakdown by default (analyze_dataframe_with_scores groups by any column, but is not called in training); no confidence intervals (metrics.bootstrap_confusion_matrix exists but is never called).
    • Tests: none in this copy.
